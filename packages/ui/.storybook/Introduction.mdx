## Work with a component

1. Choose a component and open its Docs or an individual story.
2. Adjust Controls and try the interaction with mouse and keyboard.
3. Use Theme to compare Blue or Green in light/dark mode.
4. Inspect the Accessibility panel and test the composition in the intended screen.

## The DevMentor journey

Share link → mentor profile → time, duration and price → sign-in → Checkout → text session → session ends → written answer → private note review.

Sessions are text only and last 25 or 50 minutes. Mentor profiles show the person's
identity and work so mentees can decide who to book. These examples cover the UI;
the application connects it to the backend.
