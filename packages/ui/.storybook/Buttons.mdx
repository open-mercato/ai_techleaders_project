## Composition and use

Use **primary** for the main action, **neutral** for supporting actions and **error**
for destructive actions. Icon-only buttons need an accessible name. Loading is a
composition of disabled, aria-busy and an icon.

Form and dialog footers align right, with the secondary action before the primary
submit action in both DOM and visual order. Preserve that order when buttons wrap.
Sign-in uses full-width buttons: a neutral provider alternative, a primary email
submit action, and separate centered back navigation below the form.

<Canvas of={ButtonStories.LoadingComposition} />

Supported `variant` aliases are: default →
primary/filled, outline → neutral/stroke, secondary → neutral/lighter,
destructive → error/filled, ghost → neutral/ghost. The `default` and `icon`
sizes mean 36px, `lg` means 40px. New code uses md/sm/xs/xxs explicitly.

Action colors use dedicated contrast roles. Filled actions use readable white
labels in both modes; lighter and stroke actions use stronger text colors. Keyboard
focus has an outer outline separated from the button by a gap.

Use visible text for important actions, reserve icon-only controls for familiar
actions with accessible names, and keep touch targets spacious. Check contrast in
the intended composition when adding a new theme or overriding a color.
