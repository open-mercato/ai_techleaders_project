# Prototype assets

- `developer-mentoring.png`: original artwork generated with OpenAI's built-in
  image generation tool on 7 September 2026. It depicts fictional developers and
  does not represent a real mentor. Transparent PNG, 1536 × 1024.
- `devmentor-star.svg`: a vector rendering of the blue four-point star used in
  the DevMentor wordmark. Used as the prototype favicon; Storybook uses the same
  mark for its catalogue favicon.
